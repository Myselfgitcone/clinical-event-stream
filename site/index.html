Clinical Event Stream

HL7 FHIR R4 bundles for thousands of synthetic patients, validated against contracts, de-identified before anything reaches silver, and modelled as a star schema. Every number on this page is read from summary.json, which the pipeline writes after each run.

How it runs

Synthea (seeded)  →  FHIR R4 bundles  →  contracts/*.yaml validate  →  bronze (identified) + quarantine
                                                                           ↓ de-identification, 18 classes, tested
                                                                       silver (pseudonymous, dates shifted, ZIP3)
                                                                           ↓ dbt on DuckDB, 27 models, 90+ tests
                                                                       gold star schema  →  summary.json / weekly.json  →  this page
                                                                           ↓ CES_TARGET=azure
                                                                       ADLS Gen2: bronze / silver / gold / published
